# User Stories

| ID | Role | User Story | Acceptance Criteria |
|----|------|-----------|---------------------|
| US-01 | User | As a user, I want mendaftarkan akun dengan data lengkap, so that saya dapat menggunakan sistem | Given data diisi, When klik register, Then akun berhasil dibuat |
| US-02 | User | As a user, I want login dan reset password menggunakan OTP, so that saya dapat mengakses akun dengan aman | Given lupa password, When klik reset, Then OTP dikirim ke email |
| US-03 | User | As a user, I want mencari dan memfilter barang, so that saya dapat menemukan barang dengan cepat | Given input kata kunci, When klik cari, Then hasil ditampilkan sesuai filter |
| US-04 | User | As a user, I want menyewa barang dan melakukan pembayaran, so that saya dapat menyelesaikan transaksi | Given pilih barang, When bayar, Then transaksi berhasil |
| US-05 | User | As a user, I want mengelola katalog barang saya, so that barang dapat disewakan | Given masuk katalog, When tambah/edit barang, Then data tersimpan |
| US-06 | User | As a user, I want melihat denda keterlambatan, so that saya memahami konsekuensi | Given terlambat, When cek pengembalian, Then denda muncul |
| US-07 | User | As a user, I want menggunakan chatbot AI, so that saya mendapatkan bantuan | Given tanya chatbot, Then sistem memberikan jawaban |
| US-08 | User | As a user, I want melihat riwayat sewa dan notifikasi, so that saya dapat memantau status | Given buka riwayat, Then status transaksi ditampilkan |
| US-09 | Admin | As an admin, I want memverifikasi transaksi, so that sistem tetap terkontrol | Given ada transaksi, When verifikasi, Then status berubah menjadi disetujui |
